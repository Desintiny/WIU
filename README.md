Game controls 

Movement:
WASD - walking

Events:
1, 2 ,3 (no. depending on amt of choices) - choosing of choice

Combat:
IJKL - basic attack (depending on direction)
E - ability menu
Q - items
1, 2, 3 (no. depending on amt of abilities or items) - choosing of ability or item

Inventory:
1 - Use an item (Use no. keys to select which item to use)
2 - Equip an item (Use no. keys to select which item to equip)
3 - Exit
